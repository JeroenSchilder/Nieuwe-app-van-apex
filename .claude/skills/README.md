# Skills

De skills in deze map komen uit [getagentseal/founder-playbook](https://github.com/getagentseal/founder-playbook)
(commit `e811e63`, MIT-licentie, zie `LICENSE-founder-playbook`).

Claude Code laadt ze automatisch in elke sessie op deze repo. Begin met `diagnose` als je niet weet welke past.

Voor sales vooral relevant: `spin-selling`, `influence`, `100m-offers`, `money-models`, `100m-leads`, `mom-test`.

## Instagram-content (Ootto)

De Instagram-skills komen uit [Ootto-AI/claude-content-skills](https://github.com/Ootto-AI/claude-content-skills)
(commit `5263be7`, MIT-licentie, zie `LICENSE-ootto-content-skills`).

Begin met `content-factory`: die voert de hele pipeline uit (idee → hook → script → reel → caption → comment-naar-DM).
Losse stappen: `viral-hook-writer`, `reel-scripter`, `reel-builder`, `caption-and-hashtags`, `content-calendar`,
`comment-responder`, `carousel-builder`, `content-audit`, `analytics-readout` en meer.

`agent-reach` is bewust niet overgenomen: die skill claimt elk zoek-, URL- en GitHub/commit-verzoek
(ook gewoon programmeerwerk in deze repo), laat Claude installatie-instructies van een externe URL volgen en vraagt om cookies.
Skills die ernaar verwijzen werken zonder; Claude zoekt dan via de gewone webtools.
